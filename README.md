# МедКлассификатор (medbot)

Сервис первичной классификации жалоб пациента по одному тексту: определяет
вероятный класс диагноза, уверенность, шаги подтверждения и флаг urgent
(необходимость экстренной реакции).

## Стек
- Python, pandas, scikit-learn — классификатор жалоб
- Streamlit — витрина для проверки ответов
- Собственный регресс-сьют (`tests/run_tests.py`) — без внешних тестовых фреймворков

## Ключевые цифры
- **213 классов** первичных жалоб, датасет **7 209 строк**
- **Регресс-щит: 392 кейса** (368 стресс-банковых + 24 базовых), прогон **392/392 PASS**
- Уверенность high/medium — выдаётся описание и шаги подтверждения; low — витрина показывает нейтральную подпись

## Архитектура predict
1. Базовый классификатор возвращает топ-5 классов с вероятностями;
2. **Антоним-гвард** (wave5b): направление давления по маркерам и цифрам
   (>= 140 / <= 95) — исправляет путаницу «гипертония/гипотония»;
3. **Криз-гвард** (wave6c): давление >= 180/120 или «давление NNN/до 180+»
   принудительно поднимает urgent — даже если криз схлопнулся в «гипертонию»;
4. Справочник советов (`knowledge.json`): desc / confirm / urgent / draft;
   черновые описания пациенту не выдаются.

## Безопасность
- Журнал дефектов (`defects_log.json`): D-001...D-007, все с резолюциями.
  Ключевые закрытия: D-006 (safe-side путаница криз/ИМ) и D-007
  (urgent-триггер для криза — закрыт криз-гвардом).
- Черновые записи справочника не показываются пациенту.
- Прогрессия экспериментов и всех волн — в истории коммитов репозитория.

## Запуск

    python tests/run_tests.py   # регресс-сьют: ИТОГ: PASS — 392/392
    streamlit run medbot.py     # витрина классификатора
