# MedBot Duo — интеллектуальная система первичной диагностики

**Автор и создатель модуля:** Алексей Буланкин (alexeybulankin5-source)

MedBot Duo помогает сориентироваться в симптомах, но **не заменяет консультацию врача**.
При тревожных признаках — обращайтесь за неотложной помощью: 103 или 112.

## Возможности
- **Анализ жалоб** — описание симптомов обычным текстом: 213 диагностических классов,
  вероятности, рекомендации, адаптивные уточняющие вопросы.
- **Красные флаги** — правила срочности (red_flags.yaml + правила в коде) с приоритетом
  над сырыми сходствами модели; при опасных признаках — баннер вызова скорой (103/112).
- **Анализы** — разбор лабораторных показателей (лабораторная база + векторизатор).
- **Снимки и документы** — распознавание изображений (OCR) и чтение PDF-заключений;
  интерпретация снимка — только врач, модель поясняет текст заключения.
- **ЭКГ** — пояснения по электрокардиограмме.
- **Второе мнение** — RAG-подсказки по знаниевой базе.
- **Аналитика** — статистика классов, лог нераспознанных запросов, обратная связь.

| Файл | Назначение |

## Данные и модель
- train_set.csv — 5807 примеров, 213 классов; test_set_frozen.csv — 715 примеров;
  dataset_full.csv — 7209 строк.
- ensemble.pkl — ансамбль (словарь); эмбеддинги классов/ЭКГ/лабораторий/RAG/снимков —
  в *.npz; тексты кодируются SentenceTransformer, сходство — cosine_similarity.
- Знаниевые базы: knowledge.json, rag_knowledge.json, ecg/lab/xray_knowledge.json.
- model_version.json — md5 артефактов, holdout_top1, дата сборки.

## Оценка качества
holdout.py (отложенная выборка), slice_eval.py (срезы), stroke_eval.py (зонд инсульта),
tests_regression.py, tests/test_safety.py, tests/test_suite.json, tests/stress_bank.json.

## Запуск
    pip install -r requirements.txt
    streamlit run app.py
