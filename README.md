# Медицинский классификатор жалоб (v17-rfguard)

Модель первичной категоризации бытовых жалоб: 176 классов заболеваний,
~6650 эталонных фраз. Не является диагностическим инструментом.

## Архитектура
- эмбеддинги: `cointegrated/rubert-tiny2` (SentenceTransformers)
- два LR-классификатора: colloquial (бытовые фразы) и mixed (клинические)
- роутер LR выбирает вес ветки (софт-роутинг по вероятностям)
- скоринг: бленд `0.35*LR + 0.65*косинусная похожесть на эталон`
- NN-guard: точное совпадение фразы с эталоном на 0.97+ даёт high
- санити: минимум 2 слова + (отрыв лучшего класса от медианы >= 0.145
  ИЛИ абсолютная похожесть >= 0.755) — иначе low
- шкала уверенности: high / medium (показ альтернатив) / low (уточняющий вопрос)
- экстренные паттерны (кардио, инсульт и т.п.) перехватывают ввод до диагноза

## Известные ограничения
- пограничные зоны (гастрит/ГЭРБ, холецистит/ЖКБ) частично overlap по симптомам:
  такие случаи намеренно отвечают medium с альтернативами
- правила rule_bonus/infra: скоринг смещается к паттернам, см. medbot.py
- классы без реальных клинических данных: только бытовые описания симптомов
