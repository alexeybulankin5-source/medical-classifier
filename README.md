# 🩺 MedBot Duo

Интеллектуальная система первичной диагностики: анализ жалоб, лабораторные
нормативы, расшифровка рентгена и ЭКГ, аналитика и «второе мнение».

> **Дисклеймер.** MedBot Duo помогает сориентироваться в симптомах, но не заменяет
> консультацию врача. При тревожных признаках — обращайтесь за неотложной помощью
> (скорая: 103 / 112).

## Состав

| Вкладка | Что делает |
|---|---|
| 📝 Жалобы | Классификация жалоб на 213 классов, топ-5 направлений, уточняющие вопросы |
| 🧪 Анализы | Нормативы по полу и возрасту, интерпретация отклонений |
| 🦴 Снимки | Расшифровка рентгена |
| 📈 ЭКГ | Расшифровка кардиограммы |
| 📊 Аналитика | Отчёт для врача, журнал нераспознанных запросов |
| 💬 Второе мнение | Обсуждение случая |

## Как устроена классификация

1. **Энкодер** (`sentence_transformers`) переводит жалобу в эмбеддинг; косинусные
   сходства по классам дают сырые скоры.
2. **Ada-слой** (уточняющие вопросы): при малом отрыве система задаёт до трёх
   вопросов, ответы канонизируются и переранжируют скоры. Форма стабильно отдаёт
   фразы независимо от версии Streamlit (`_ans_val`), фразы канонизируются в
   `rerank` и `enrich_query` — одинаковые слова на обеих сторонах.
3. **Правила-оверрайды** (`_redflag_check`, `_bp_override`, `_allergy_override`,
   `_tonsil_override`, `_symptom_override`) — критические признаки важнее порогов.
4. **Гейты решения** (`score_parts`): `danger` (скорая) имеет приоритет над
   `confident` (порог score ≥ 0.55 и отрыв ≥ 0.08).

## Правила безопасности, зашитые в код

- Признаки острого состояния (боль за грудиной с иррадиацией, холодный пот,
  ригидность шеи и др.) стреляют на голом тексте — до порогов и уточняющих вопросов.
- Ключевые слова danger-правил нормализуются по «ё/е» на обеих сторонах сравнения.
- Триада отрицательных различителей (ГБН): свободный подбородок к груди +
  нет светобоязни + нет вегетатики — согласованная картина, повышает уверенность.
- При `danger` вердикт не называется — только экстренная рекомендация.

## Запуск

    pip install -r requirements.txt
    streamlit run app.py

## Тесты

    python -m pytest tests_regression.py -v

Регресс охватывает: кейс ГБН (уверенная карточка при триаде отрицаний),
ригидность шеи (danger-триггер), инфарктный кейс (danger на голом тексте с «ё»).

## Структура

    app.py               — Streamlit-приложение (вкладки, оверрайды, гейты)
    adaptive.py          — Ada-слой: вопросы, канонизация, переранжировка
    pipeline.py          — энкодер, скоринг, score_parts (danger/confident)
    knowledge.json       — база знаний
    class_embeddings.npz — эмбеддинги классов
    ensemble.pkl         — ансамбль скоринга
    tests_regression.py  — регресс-тесты
    unknown_queries.txt  — журнал нераспознанных запросов
