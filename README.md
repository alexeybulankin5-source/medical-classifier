# MedBot Duo — симптом-в-класс классификатор

Streamlit-приложение первичной ориентировки по симптомам: пользователь описывает жалобы
обычным языком («давит за грудиной при подъёме на лестнице»), система сопоставляет их
с базой на **449 диагнозов и состояний** и показывает вероятности, описание, рекомендации
и ссылки на источники. Приложение не заменяет консультацию врача.

## Возможности

- пять вкладок: жалобы, анализы, снимки (рентген), ЭКГ, аналитика;
- топ-3 кандидата с вероятностями; при уверенности 0.85+ альтернативы скрываются;
- адаптивные уточняющие вопросы (например, для боли в животе);
- urgent-правило: при почти равных шансах (зазор до 0.03) приоритет отдаётся более
  опасному диагнозу — инфаркту миокарда, инсульту, ТЭЛА;
- для экстренных классов — красный баннер с призывом вызвать скорую (103/112);
- правило конкретики: симптомные классы («Боли в животе») уступают место конкретным
  диагнозам, когда их вероятности сравнимы.

## Структура репозитория

| файл | роль |
|---|---|
| `app.py` | Streamlit-приложение |
| `knowledge.json` | база: 449 классов (desc, confirm, recommendations, urgency) |
| `class_embeddings.npz` | векторы классов (multilingual-e5-small, passage:) |
| `lab/xray/ecg/rag_knowledge.json` + их `*_embeddings.npz` | модули анализов, снимков, ЭКГ и RAG-цитат |
| `vectorizer.py`, `scan_vectorizer.py`, `lab_vectorizer.py`, `rag_vectorizer.py` | скрипты перегенерации эмбеддингов |
| `tests_regression.py` | регрессионный набор (13 кейсов) |
| `holdout.py` | holdout-оценка на размеченных текстах |
| `tests/stress_bank.json`, `tests/test_suite.json` | стресс-банк и набор кейсов |

## Запуск

    pip install -r requirements.txt
    streamlit run app.py

Модель эмбеддингов (`intfloat/multilingual-e5-small`) скачивается при первом запуске.

## Тестирование

    python tests_regression.py
