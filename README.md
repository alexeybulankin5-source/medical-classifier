# 🩺 MedBot Duo

Интеллектуальная система первичной диагностики по жалобам пациента.
Приложение: [Streamlit Cloud](https://medical-classifier.streamlit.app)

## Как работает

1. Пользователь описывает жалобы текстом.
2. Текст кодируется моделью **intfloat/multilingual-e5-small** (SentenceTransformer, 384-мерные векторы).
3. Косинусное сходство с эмбеддингами классов из `class_embeddings.npz`.
4. Порог уверенности **0.65**: выше — выдаём диагноз, ниже — просим переформулировать и пишем запрос в журнал неизвестных.

## Возможности интерфейса

- **📝 Жалобы** — диагноз + уверенность, рекомендации (с фолбэком на шаги подтверждения из базы, поле `confirm`), красные флаги, триаж срочности: `emergency`/`call_ambulance` — жёлтое предупреждение, `doctor_visit` — плановая консультация. Топ-3 альтернативных диагноза по соседним классам.
- **🧪 Анализы** — загрузка лабораторных файлов (PDF, JPG, PNG, TXT) с распознаванием текста.
- **📊 Аналитика** — журнал нераспознанных запросов, статистика базы знаний (всего диагнозов / срочные / с рекомендациями / с флагами), поиск по базе.

## Архитектура и файлы

| Файл | Назначение |
|---|---|
| `app.py` | Streamlit-интерфейс, вывод результатов |
| `medbot.py` | Классификатор: E5-энкодер (офлайн, ONNX) + legacy sklearn-пайплайн |
| `knowledge.json` | База знаний: 213 классов (desc, urgent, confirm, red_flags, recommendations) |
| `class_embeddings.npz` | Эмбеддинги классов для рантайма |
| `e5_onnx/parts_00, parts_01` | ONNX-энкодер E5, разбит на куски (<100 МБ для GitHub) |
| `pipeline.joblib`, `emb_all.npz`, `labels.npy` | Legacy sklearn-пайплайн — используют тесты и сравнение качества |
| `dataset_full.csv` | Исходный датасет (нужен для `holdout.py`) |
| `tests/` | Набор тестов: 395/399 прохождение |
| `holdout.py` | Оценка качества на отложенной выборке |
| `vectorizer.py` | Вспомогательный модуль векторизации |

## Деплой

- Хостинг: Streamlit Cloud, автосборка из `main` этого репозитория.
- Модель скачивается с Hugging Face при холодном старте (~1–3 мин), ресурсы кешируются через `@st.cache_resource`.
- Пуш из Colab: токен из Colab Secrets (`GITHUB_TOKEN`) подставляется в remote-URL на момент пуша и сразу вычищается.

## История восстановления (ноябрь 2025)

- Рабочая версия `medbot.py` восстановлена из снапшота `wave7b-final` после деградации, вызванной файлом-двойником `knowledge (1).json` (коммит `6a2a174` перезаписал базу знаний).
- В `app.py` добавлены: рекомендации с фолбэком на `confirm`, топ-3 альтернативных диагноза, триаж по полю `urgency` (коммит `0c6d828`).
- Уборка репозитория (коммит `6936031`): удалены двойник базы знаний и 8 одноразовых патч-скриптов/артефактов отладки (−2207 строк). Тяжёлые файлы проверены grep'ом — оставлены как несущие.
