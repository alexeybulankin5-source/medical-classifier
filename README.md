# 🩺 MedBot Duo

Интеллектуальная система первичной диагностики на Streamlit: анализ жалоб, лабораторных
анализов, рентгеновских снимков и ЭКГ с объяснимым выводом и ссылками на источники.

> **Дисклеймер.** Проект демонстрационный и не является медицинским изделием. Он не ставит
> диагнозов и не заменяет врача. При опасных симптомах (боль в груди, одышка, отёк лица и
> горла, потеря сознания) немедленно обращайтесь за помощью: 103 или 112.

## Возможности

- **Анализ жалоб** — семантический поиск по базе диагнозов (`intfloat/multilingual-e5-small`,
  косинусная близость, порог показа 0.65), топ-5 кандидатов и альтернативы;
- **Красные флаги и оверрайды** — правила сильнее сходства: опасные жалобы (например, отёк
  губ/лица после еды) перехватывают гипотезу у менее опасных классов и добавляют предупреждение;
- **Объяснимость** — экспандер «Почему такой вывод»: сходство, порог, топ-5, сработавшие правила;
- **Источники** — детерминированный подбор тем из клинических справочников по правилам
  «диагноз → тема» (без эмбеддингов: замеры показали, что косинусный подбор на этой базе
  даёт нерелевантные совпадения при любом пороге);
- **Анализы** — разбор бланка: поиск паттернов, интеграция с контекстом жалоб;
- **Снимки (рентген)** и **ЭКГ** — проверка по собственным базам знаний;
- **Аналитика** — обратная связь пользователя (👍/👎) и лог нераспознанных запросов.

## Быстрый старт

```
pip install streamlit sentence-transformers numpy scikit-learn pillow
streamlit run app.py
```

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `app.py` | Приложение Streamlit: вся логика классификации, правил и интерфейса |
| `knowledge.json` | База диагнозов для жалоб: описание, рекомендации, красные флаги, срочность |
| `class_embeddings.npz` | Эмбеддинги классов для семантического поиска |
| `rag_knowledge.json` | Темы источников с URL и описаниями |
| `lab_knowledge.json`, `xray_knowledge.json`, `ecg_knowledge.json` | Базы для анализов, снимков и ЭКГ |
| `feedback.csv` | Отзывы пользователей |
| `unknown_queries.txt` | Лог нераспознанных запросов |

## Как устроена логика

1. Запрос кодируется моделью e5-small и сравнивается с эмбеддингами классов;
2. Срабатывает гейт тарабарщины — бессмысленный ввод обнуляет уверенность;
3. Правила красных флагов и оверрайдов могут скорректировать гипотезу (правило сильнее сходства);
4. Вывод: диагноз, рекомендации, красные флаги, уровень срочности, альтернативы;
5. По диагнозу и жалобам подбираются темы источников — детерминированные правила;
6. Отзыв пользователя пишется в `feedback.csv` и виден во вкладке «Аналитика».

## Тестирование

Функции правил проверяются без запуска интерфейса: тело функции извлекается из `app.py`
через `ast`, темы сверяются с `rag_knowledge.json`, затем функция исполняется на наборе
тест-кейсов (ожидаемый диагноз → ожидаемые темы; пустой кейс → пустой список).
