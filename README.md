# Медицинский классификатор симптомов

Симптом-в-класс: пользователь описывает жалобы обычным языком («давит за грудиной при подъёме на лестницу»), система возвращает наиболее вероятное состояние из справочника на 222 диагноза и состояний. Если запрос не распознан как медицинский текст — честно отвечает «нераспознан».

## Как это работает

1. **База знаний** — `knowledge.json`: 222 класса, у каждого человеческое описание на 300+ символов: симптоматика, отличия от похожих состояний, красные флаги, куда обращаться.
2. **Эмбеддинги** — `class_embeddings.npz`: описания (имя + текст) прогнаны через `intfloat/multilingual-e5-small` с префиксом `passage:`, нормализованы в единичный вектор.
3. **Запрос** — фраза пользователя кодируется той же моделью с префиксом `query:` и матрично сравнивается косинусной близостью со всеми классами.
4. **Порог** — если максимальная близость ниже границы, ответ «нераспознан»: модель не выдумывает диагноз на бессмыслице.
## Чем база отличается от справочника

Ключевая работа проделана не в объёме, а в **разводчиках** — парах классов, которые эмбеддер слипает:

- **фонетические ловушки**: уретрит/радикулит, кератит/кариес, розовый лишай/рожистое воспаление — разные сущности со сходной формой слова;
- **антонимы**: гипотиреоз/гипертиреоз — разведены не зеркальным каркасом (он, как выяснилось, сам работает на сходство), а разными словарями: Хашимото и миксидема против Базедовой болезни и тиреотоксикоза;
- **смежные состояния**: цистит/простатит (пол и локализация), тромбофлебит/тромбоз глубоких вен (глубина и последствие), ангина/ОРВИ (гнойный налёт против катаральных явлений), лактостаз/мастит (температура и эффект опорожнения).

Описания целенаправленно содержат конструкции «в отличие от X» — это одновременно медицинская ценность текста и рабочий инструмент развязки эмбеддингов.

## Известные пределы

Финальная матрица сходства честно показывает родство, которое мы сознательно оставили:

| Пара | Сходство | Природа |
|---|---|---|
| тиреоидит Хашимото ↔ гипотиреоз | 0.9588 | причина и её синдром — родство подлинное |
| сахарный диабет 1 ↔ 2 типа | 0.9461 | признанный предел: обе формы описаны точно, дальнейшее разведение вредило бы текстам |
| ринит ↔ аллергический ринит | 0.9438 | общее и разновидность |

Самые удалённые классы: болезнь Альцгеймера и эпилепсия, 0.8551 — пространство модели сжатое, такой разброс — признак здорового индекса.
## Запуск

В Colab:

    !pip install -q sentence-transformers

    import json, numpy as np
    from sentence_transformers import SentenceTransformer

    enc = SentenceTransformer("intfloat/multilingual-e5-small")
    kb = json.load(open("knowledge.json", encoding="utf-8-sig"))
    emb = np.load("class_embeddings.npz", allow_pickle=True)
    E = np.asarray(emb["embeddings"]); names = [str(x) for x in emb["names"]]

    def classify(text, threshold=0.55):
        q = enc.encode(["query: " + text], normalize_embeddings=True)[0].astype(np.float32)
        sims = E @ q
        best = int(np.argmax(sims))
        return (names[best], float(sims[best])) if sims[best] >= threshold else ("нераспознан", float(sims[best]))

    print(classify("постоянная жажда и частое мочеиспускание"))
    # ('сахарный диабет 2 типа', ~0.8)
## Тестирование

Регрессионный набор `tests_regression.py` — 13 кейсов-фиксаций: типичные жалобы (стенокардия, мигрень, астма), ловушки из слепых пар и два gibberish-запроса, обязанных вернуть «нераспознан». Запуск:

    python tests_regression.py

Текущее состояние: **13 PASS / 0 FAIL**, тег `v1.0` — все 222 класса обогащены.

## Методология волны

База строилась итеративными партиями по ~14-24 класса с обязательным циклом: разведка коротышей → обогащение с разводчиками → перегенерация индекса → топ слепых пар → регресс → коммит. Каждый FAIL регресса разбирается и чинится переклейкой описаний — ни один не остаётся висеть.

## Дисклеймер

Проект — демонстрация и учебный инструмент, не медицинское изделие и не замена консультации врача. Диагноз по одной фразе ставить нельзя даже модели с идеальным индексом.

## Роадмап

- живой тест свежей базы провокационными запросами (включая случаи из слепых пар);
- аудит ~97 классов, обогащённых до волны, на скрытые пары выше 0.90;
- калибровка порога «нераспознан» на профессиональной лексике;
- топ-3 кандидата в ответе вместо одного.
