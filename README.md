# Медицинский классификатор жалоб (прототип)

Streamlit-приложение: пользователь описывает жалобы обычными словами, модуль сопоставляет
их с базой нозологий по семантическим эмбеддингам, показывает кандидатов с оценками,
уровень срочности и красные флаги, и предлагает обсудить случай с LLM («Второе мнение»).

> **Это прототип, а не медизделие.** Приложение не ставит диагнозов и не заменяет врача.
> При опасных симптомах — скорая: 103 или 112.

## Классификация (вкладка «Жалобы»)

1. Свободный текст кодируется энкодером **multilingual-e5-small** с префикс-протоколом:
   запрос — `query: ...`, эталоны классов — `passage: ...`. Протокол обязателен:
   без него топ-1 падает примерно на 38 п.п.
2. Косинусная близость к **прототипам классов** (`class_embeddings.npz`,
   213 классов) даёт топ-5 кандидатов.
3. Диагноз показывается при сходстве ≥ 0,65; при слабой уверенности — альтернативы (топ-3).
4. Правила-оверрайды корректируют гипотезу по характерным признакам запроса:
   давление (`_bp_override`), аллергия, миндалины, симптомные паттерны
   (`_symptom_override`), проверка красных флагов (`_redflag_check`).
   Экзотические классы отфильтровываются; при ничьей argmax предпочтение отдаётся
   классу, чьё имя дословно встречается в запросе.
5. Для выбранного класса выводятся: описание из базы знаний, уровень срочности,
   блок «Почему такой вывод» (объяснимость) и «Что говорят источники»
   (RAG по клиническим рекомендациям).

## Красные флаги

`red_flags.yaml`, версия 7: 10 флагов. Структура флага: `id`, `title`,
`patterns` (регулярки), `except` (исключения), `message` (текст предупреждения).
Проверка — `safety.assess(text)`; сработавшие флаги показываются пользователю
и попадают в контекст «Второго мнения» как «СРОЧНО: ...».

Контракт: у каждого флага должно быть поле `message` — UI устойчив к его отсутствию,
но YAML проверяется перед деплоем.

## Вкладка «Второе мнение»

- Чат с LLM (YandexGPT) на контексте случая: жалобы, вердикт классификатора, срочность.
  Второе мнение опирается на вердикт, а не отвечает с нуля.
- Честные границы: не записывает на приём и не знает телефонов поликлиник — подсказывает
  путь (Госуслуги «Моё здоровье», 103/112). На вкладке есть статический блок контактов.
- Диалоги логируются с контекстом случая и версией модели (e5-small-prototypes-v2).

## Прочие вкладки

- **Анализы**, **Снимки (рентген)**, **ЭКГ** — приём данных пользователя (в развитии).
- **Аналитика** — сводка последнего случая: диагноз, уверенность, топ-5 кандидатов.

## Тесты и оценка качества

- `pytest tests` — юнит-тесты красных флагов и ключевых правил.
- Готовится eval-набор живых формулировок по восьми нозологиям: инсульт, инфаркт,
  ТЭЛА, анафилаксия, менингит, внематочная беременность, аппендицит, кровотечение ЖКТ.
  Сначала — базовая линия (экзамен №1) на живом языке, затем — прирост от
  аугментации train (сейчас 5807 строк).

## Деплой

Streamlit Community Cloud, автосборка из ветки `main`. Изменение `red_flags.yaml` —
bump `version` в файле, коммит, push, пересборка 3–7 минут. Токены — только через
переменные окружения, не в коде.

## Дисклеймер

Приложение — учебный/исследовательский прототип. Оно не проходит клиническую
валидацию, не является медицинским изделием и не должно использоваться
для самодиагностики и выбора лечения. Окончательную оценку состояния делает врач.
